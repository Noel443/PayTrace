    新建工作空间

    为新的项目或业务建立独立的数据源、业务文档和排查记录。

    创建后可配置服务器和知识文档。新空间不自动生成案例或交易数据。

    添加日志数据源

    菜单模式：先在运行 PayTrace 的电脑连接 VPN；填写目标资产地址，堡垒机可使用 SSH Key/Agent 免密登录；如使用密码认证，再填写堡垒机密码。资产账号由堡垒机托管，无需目标机密码。

    堡垒机连接设置

    菜单模式会登录堡垒机并按目标地址选择资产；SSH 模式使用 ProxyJump。菜单模式不支持短信验证码或二次密码提示。

    这台服务器上的日志

    SSH 账号只填一次。可填写具体文件，或用 * / ? 筛选当前目录下的文件。

    例如 *-console.log 匹配 trx-console.log、daemon-console.log、merchant-console.log、boss-console.log，不匹配截图中的日期归档文件。服务留空时，从文件名自动识别；最多查询 20 个文件，不递归子目录。

    相对路径以日志目录为基准，目录留空则使用 SSH 账号主目录。若通过 logs 命令进入目录，请执行 pwd，将结果填入上方日志目录。

    密码由服务端保存，MySQL 模式下加密入库，不存入浏览器；保存后可测试 SSH 连接；仅执行日志读取检查和固定文本检索。

    服务器日志查询

    只读取该服务器配置的单个日志文件；当前结果不会自动合入沙箱报告或发送给 AI。
